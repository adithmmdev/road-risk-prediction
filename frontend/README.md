# Road risk map

React and Leaflet interface for Chennai road risk exploration. See the [root README](../README.md) and [artifact requirements](../docs/data-and-models.md) before running inference.

```bash
npm ci
npm run dev
npm run lint
npm run build
```

Vite forwards `/api` to localhost:5000. Set `VITE_API_BASE_URL` when hosting the API elsewhere.
